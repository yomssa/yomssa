# 핏로그 — 체중·운동 기록

설치 없이 브라우저에서 쓰는 체중 + 운동 기록 앱입니다.

## 기능
- **체중**: 날짜별로 아침 ☀️ / 저녁 🌙 따로 기록 (입력 후 바로 저장)
  - 하루 변동(저녁−아침), 이전 아침 대비 증감 표시
- **운동**: 날짜별로 여러 개 기록 — 이름, 세트, 횟수, 무게, 시간, 메모
  - 항목을 누르면 수정, ✕로 삭제 / 이전에 쓴 운동 이름 자동완성
- **그래프**: 아침·저녁 체중 꺾은선 그래프 (1주/1달/3달/1년), 기간 변화·평균, 운동한 날 잔디
- **전체 기록**: 날짜별 목록, 누르면 해당 날짜로 이동
- **백업**: JSON 내보내기/가져오기
- 오프라인 동작, 휴대폰 홈 화면에 추가 가능(PWA), 다크 모드 지원

## 실행
```bash
cd fit-log
python3 -m http.server 8000
# http://localhost:8000 접속
```
`index.html`을 바로 열어도 동작합니다(오프라인 캐시만 빠짐).

## 아이폰에 앱으로 설치
1. 배포된 주소를 **Safari**로 엽니다 (크롬 X)
2. 아래 **공유 버튼(□↑)** → **홈 화면에 추가** → 추가
3. 홈 화면의 **핏로그** 아이콘으로 실행하면 주소창 없이 전체 화면 앱으로 열립니다

- 인터넷 없이도 실행됩니다
- 기록 화면에서 **좌우로 밀면** 날짜가 바뀝니다
- **백업**: 전체 기록 → 내보내기 → 공유 시트에서 **파일에 저장** (iCloud Drive)
- 홈 화면 앱으로 설치하면 Safari의 "7일 미사용 시 데이터 삭제" 정책을 받지 않지만, 앱 아이콘을 지우면 기록도 지워지니 주기적으로 백업하세요

## 데이터
기록은 브라우저 `localStorage`에 저장되며 서버로 전송되지 않습니다.
기기를 바꾸거나 브라우저 데이터를 지우기 전에 **내보내기**로 백업하세요.
