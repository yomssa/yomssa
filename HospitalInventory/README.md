# 병원 재고 (iPhone 앱)

SwiftUI로 만든 아이폰용 병원 재고 관리 앱입니다.

## 기능
- 기본 품목 37종이 처음 실행 시 자동 등록 (울쎄라팁, 써마지, 리쥬란, 필러, 보톡스, 줄기세포, 약품 등)
- **날짜별 재고 수정**: 기준 날짜를 고르고 수량을 바꾸면 그 날짜 재고로 저장. 기록이 없는 날은 직전 기록이 이어짐
- 목록에서 `−` / `+` 버튼으로 바로 수량 조절, 품목을 누르면 직접 입력·메모·변경 기록 확인
- 울쎄라 팁처럼 **남은 샷 수**를 따로 관리
- **신규 품목 추가** (카테고리·단위 새로 만들기 가능), 품목 수정/삭제
- "날짜별 기록" 탭에서 날짜마다 변경 내역 (이전 → 이후) 확인
- 재고표 CSV 내보내기 (엑셀에서 열기 가능)
- 재고 0은 빨간색 표시, 검색 지원
- 데이터는 아이폰 안에 저장 (인터넷 불필요)

## 설치 방법
1. Mac에서 Xcode 15 이상으로 `HospitalInventory.xcodeproj` 열기
2. 프로젝트 > Signing & Capabilities 에서 Team을 본인 Apple ID로 선택
   (필요하면 Bundle Identifier를 고유한 값으로 변경)
3. 아이폰을 연결하고 실행(▶) — iOS 17 이상 필요
